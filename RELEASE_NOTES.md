# MUX 2

This release establishes the managed MUX Windows update channel and the redesigned control surface.

- New minimal dark production UI across the main controller and configuration dialogs.
- One-click managed updates powered by the same Velopack release mechanism used by ONX.
- Automatic release checks while MUX is running.
- GitHub Actions builds, tests, packages, and publishes every accepted `main` commit.
- Existing layouts, calibration, shortcuts, black bars, screen bars, Stream Deck controls, Auto Arrange, window pills, and physical-inch sizing remain intact.
